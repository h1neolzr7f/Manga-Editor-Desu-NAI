# 人工测试链路（P3/P4 修复影响面）

用途：本次改动（[P2] 常量引用合并、[P3] 去重、[P4] 监听守卫）集中在**导出与画布菜单**，
请在正式合并前按下列操作**从界面**逐条验证。[P1]（默认 PNG 位深度为 24位 RGB）本次**未改动**。
测试环境：`http://127.0.0.1:8000/index.html#`（一键启动后自动打开）。

## A. [P3-1] 网格恢复（`restoreGridAfterExport`）——重点

改动的行为：`clipCopy` 与 `cropAndDownload` 原本各自复制了一段"导出后恢复网格"的收尾逻辑，现已合并为一个共享函数。**行为应完全不变**。

1. 打开编辑器，点 **画布 → 网格**（`Ctrl+G`），确认画布上出现蓝色网格线。
2. 触发 **导出**（`Ctrl+S` 或菜单下载）：
   - 下载应正常开始；
   - 下载开始后，**网格应仍然可见**（导出前会临时移除网格，导出后再恢复）。
3. 触发 **复制到剪贴板**（分享菜单 / `snsTweet` 路径）：
   - 应提示"已复制"，剪贴板内容为画面；
   - **网格应仍然可见**。
4. **关键边界**：先关闭网格（`Ctrl+G`，网格不可见）→ 再导出/复制 → 网格**不应**被重新画出来。
5. 失败场景也应恢复：把 **下载 DPI** 设为极大值（如 1800）触发导出上限提示，导出完成后检查网格是否仍按第 2/4 步的规则恢复。

## B. [P3-2] 画布背景色标（`syncExportBackgroundLabel`）

改动的行为：删除了 `formatExportColorHex` 包装函数，直接调用 `rgbToHex()`。

1. 打开 **画布 → 画布背景**。
2. 点击该行的颜色按钮，在弹出的取色器里换成**任意颜色**（例如纯红 `#ff0000`、然后再试 `#0a0b0c`）。
3. 检查该行左侧的**十六进制文本**与右侧的**小色块**：
   - 文本应为**大写**（如 `#FF0000`）；
   - 色块颜色应与文本一致；
   - 重复切换多次，二者不应失配。
4. 重启编辑器（或刷新），确认保存的背景色能正确回填到文本/色块。

## C. [P3-3] 导出上限常量「单一来源」（[P2] 的合并点）

改动的行为：`image-util.js` 不再自带 `8192/40MP`，改为读取 `NaiMangaPageSize`。

1. 画布菜单显示 **竖图像素 / 横图像素** 与 **预计导出大小**。
2. 把 **下载 DPI** 调到上限附近（如 1200、1500、1800）：
   - 像素预览行应随 DPI 变化；
   - 若触到上限，应出现"已达导出上限"提示，且像素预览与"预计导出大小"的尺寸应**相互一致**。
3. 实际导出该 DPI，确认导出图片的实际像素与预览显示的**完全一致**（不要出现差 1px 或明显不一致）。

## D. [P4] 画布事件监听不重复注册（`exportEstimateCanvasBound`）

改动的行为：`syncExportSizeEstimate()` 每次调用都会注册 `canvas` 的 `object:added/modified/removed` 监听，现已加守卫只注册一次。

1. 在画布上**反复**执行会触发 `syncExportSizeEstimate` 的操作：
   - 打开 **画布 → 导出格式** 下拉，来回切换 PNG/JPEG/WebP **多次**（每次 `change` 都会走一次该函数）；
   - 期间同时做几次 **添加/移动/删除对象**（文字、图片、面板）。
2. 观察 **预计导出大小**：
   - 应能正常更新，**不应**出现越切越卡、响应变慢、或数值抖动异常的现象（旧实现会随切换次数线性叠加监听）。
3. 打开浏览器 **DevTools → Performance/Console**（可选）：
   - 单次移动对象时，估算的排程应只发生一次（函数内有 350ms 防抖，这是预期）；
   - Console 不应因该路径报错。
4. 长时间会话抽查：连续编辑 5–10 分钟后，再做第 1 步，确认仍不卡顿。

## E. 回归确认（不应受影响）

1. **导出格式/品质**：PNG 时品质选择应禁用；JPEG/WebP 时品质生效。
2. **导出位深度**：仅 PNG 生效；非 PNG 时该项禁用。
3. **文本聚焦**：点击画布右/下边缘外的已聚焦文本对象，**视图不应整体漂移**（`64c1897` 的修复）。
4. **DPI 持久化**：把 DPI 改成非法值（如 `-5`）后再失焦，应回退到上一次有效值而不是 300；重启后仍保留。
