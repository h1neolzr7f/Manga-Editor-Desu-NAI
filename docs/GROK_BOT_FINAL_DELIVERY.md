## 2. 产品目标：最少操作、最低学习成本
- **首页和编辑器清晰漂亮**：统一字体、图标、色彩、间距、按钮样式与状态提示。画布是主角，整理拥挤的右侧面板/工具栏；移除重复、无效入口，常用功能直达，高级功能折叠。
- **零教程也能用**：首次启动有简短且可跳过的配置引导；提供合理默认值、直白的中文用语、示例提示词、明确错误与恢复指引，不让小白理解技术术语才能操作。
- **典型流程尽可能短**：导入图片 → 鼠标框选/描述 → 参考图（可选）→ 生成预览 → 确认应用；字幕则是识别 → 检查修改 → 去字/替换 → 保存。目标是核心任务尽量 **3–5 个关键操作**完成（不计输入文字/选择本地文件），无法达到时测量并解释原因。
- 快捷键、鼠标右键、撤销/重做、拖拽、缩放、加载状态、任务取消、前后对比要直观且真正可用。收费调用必须用户主动触发，失败不得偷偷重新计费。
- **体验超过原版要有证据**：用相同任务记录原版与新版的点击次数、完成时间、错误/卡住次数、成功率和截图；不准仅凭“界面更好看”宣布胜利。

## 3. 必须完成的功能
- **GPT 编辑**：官方兼容/自定义中转与模型、文生图、局部改图、矩形/套索/笔刷蒙版、参考图换人物、角色档案、预览确认、非破坏性图层、选区外像素/分格线保护、跨页安全、撤销重做与保存重开。
- **智能字幕**：本地 Tesseract/Manga OCR、横竖排、气泡/文字定位、LaMa 去字及手动修蒙版、可编辑字幕、多页处理；消灭残影、错位、字溢出、错误擦除。
- **角色与分镜**：跨页参考图复用、减少串角；分镜识别、阅读顺序、自然语言编辑计划。识别不可靠必须供用户确认，不能乱改图。
- **架构清理**：删除死代码/失效集成/重复监听和功能，统一编辑状态，修复异步竞态、缓存、序列化、坐标/尺寸、图层顺序等问题。尽量精简；不得牺牲安全或删除有效测试来制造“全绿”。

## 4. 强制模拟用户点击 + 真实修图测试（核心验收）
**不能只跑单元测试、只截图或者只调用 API。必须在真实启动的应用中像人一样操作。**

用 Playwright + Chromium（必要时配合桌面 GUI 自动化）实际执行鼠标移动、单击、右键拖拽、套索、滚动、键盘输入、文件上传、工具切换、确认、撤销/重做、保存与重开；断言可见结果，而不是只断言按钮存在。

建立可重复运行的 **新手完整任务脚本**：
1. 全新配置启动 → 不看文档完成 API 配置/导入 2 页漫画；检验首启引导、中文提示与错误恢复。
2. 右键框选人物 → 上传参考图 → 自然语言要求替换 → 生成 → 预览前后 → 应用图层；验证原图与分辨率保留、选区外像素无变化、分格线保留。
3. 识别日文气泡 → 修正 OCR → 本地 LaMa/手动蒙版去字 → 输入中文/日文横竖排字幕；检查残影、文字溢出与定位。
4. 对上述修改连续 **撤销、重做、切页、保存、关闭、重开**，逐页核对图像像素、字幕编辑性与历史状态；测试正在生成时切页/取消。
5. 测试空白项目、超长提示词、错误 API、失败后再试、较大图片、不同窗口尺寸/缩放、高 DPI，以及鼠标右键与菜单竞争；全部操作都有清楚反馈。
6. 每条用户流程记录 **关键操作次数、耗时、成功/失败、截图与可复现步骤**。失败时先复现并定位根因，修代码，再运行该案例及相关回归；**循环直到通过**，不能仅改测试期望、隐藏异常或绕开功能。
7. 测试分层记录：Mock 回归、真实本地模型、真实 GPT Images/NovelAI API、Windows 实机。真实模型使用已授权的凭证和小额调用；中转故障（如 HTTP 530）单独标记为网络阻断，不谎称模型测试通过。
