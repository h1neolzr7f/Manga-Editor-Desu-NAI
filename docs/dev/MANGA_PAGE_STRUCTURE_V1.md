# Manga-NAI-GPT · 漫画分镜结构与自然语言编辑（V1）

> 开发分支：`feat/manga-page-structure-v1`，Draft PR #8，基于智能字幕 PR #7。
> 此文件描述 **已经实现的功能与限制**，不把像素推断说成真正的漫画语义理解。

## 用户操作

1. 在本地启动编辑器，导入漫画并进入一个画布页面。
2. 点击画布顶部 **分镜结构** → 选择「日漫（右→左）」或「普通（左→右）」→ **分析本页**。
3. 页面上以透明蓝框显示候选分镜；列表内可校正 x/y/宽/高、点击确认，也可 **左右拆分 / 上下拆分 / 删除误识别**。
4. 打开 **智能字幕** → **检测本页文字**；OCR 文字会关联对应的候选分镜。文字落在分镜边界上时不自动强行归属。
5. 分镜面板里的 **自然语言编辑计划**：
   - 「第二格把背景改成雨夜城市，保留人物和对白」→ 整格候选选区，先预览计划、确认，再进入 GPT 改图。
   - 「第二格把蓝发少女换成参考图人物」→ **不能自动识别人和轮廓**；用户确认后必须在 GPT 面板重新框选目标人物，不允许将整个分镜悄悄当作人物区域。
   - 「第三格对白改成早上好」→ 进入智能字幕，人工选气泡与原生文字图层处理，不调用 GPT 生图。
6. 可以导出 `manga-page-structure.json`，供后续角色/气泡/模型适配器使用。**导出的结构不是 OCR 识别准确度报告**。

## 算法边界

- **分镜是候选**：目前按本地缩小后的像素中近白色留白进行递归切分，只适合明显留白的版式。斜线、镂空、无边框、嵌套、跨格人物需要人工拆分/修正；单页无法识别会回退整页。
- **气泡是候选**：OCR 检出的文字框外扩形成 `bubbleCandidates`，标记为 `verified:false`。它不是检测到真实的气泡轮廓、尾巴或说话角色。
- **人物识别没有完成**：V1 不具备角色像素遮罩、跨页人物 ID 或姿态识别。人物替换强制用户再次框选。
- **自然语言解析不是大模型**：V1 仅识别显式「第几格」和常见「文字 / 人物 / 背景」词汇。遇到多个分镜、无编号、跨页等含糊表达时拒绝执行；不保证理解剧情上下文。
- **计费保护**：分析和计划都是本地工作，不消耗 GPT Image 额度。进入 GPT 面板也只是**预设**选区/提示词，用户必须再次确认生成。
- **坐标与编辑历史**：分镜浮层不是 Fabric 对象，不改原图；画布像素发生改变会令分析结果失效，必须重新扫描。手动修订的结构可以导出 JSON，尚未整合进跨页工程状态。

## 下一阶段

1. 加入可选真正的 `BubbleDetectorAdapter`，判断气泡轮廓与尾巴并关联文字，而不是简单放大 OCR 框。
2. 将 Manga OCR 作为可插拔日漫 OCR 引擎，用实际竖排漫画和假名注音测量准确度。
3. 添加 `TextInpaintAdapter`：复杂背景优先 LaMa 等离线局部修复、必要时 GPT Image；按蒙版裁剪，避免整页画风漂移。
4. 添加 `CharacterSegmenter` 和跨格 Character Bible：仅在可核验角色遮罩与参考图时开放人物半自动替换。

此 PR 处于功能开发期，不代表最终产品或可直接合并至 `main` 的版本。
