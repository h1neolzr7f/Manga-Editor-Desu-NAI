## 12. GPT 贴片接缝 + 文字检测去字（2026-10-10）

### GPT 贴片：只替换改动部分 + 整块色调一致性
- 新的高级选项「只替换模型真正改动的部分」默认开启：先在整个选区上找出大多数像素一致的偏色并扣掉（要求六成以上一致、最多 96 级），再按格子比较平均颜色和纹理反差，生成「改动蒙版」（扩大并柔化）。没改动的地方直接露出原图像素，所以不会出现浅色方块或接缝；如果整块几乎都改了（例如完整换角色），就跳过这一步，整块照旧使用。
- 接缝匹配改为以这条边上的主流色差为基准（之前是以 0 为基准，大于 28 级的统一偏色会被当成内容变化而不校正）。
- 证据在 `/workspace/shots-20261010/seam/`：
  - 用之前真实 gpt-image-2.5 的 C/D/G 结果重放（免费），比较这次的新算法关和开（不是和更早的旧代码比）：选区边上 1 像素的跳变增量 C +0.64→+0.35、D +1.02→+0.72、G +0.98→+0.42。D 的 8 像素宽带增量没变（+7.46），那里主要是新画的脸跨过了边缘，属于正常内容变化。
  - 天空案例 R 用模拟模型（整块提亮 56 级加一道彩虹，即 dogfood 第 4 页实测到的问题）：离彩虹较远区域的偏色从 11.3 级降到 7.5 级，变化超过 8 级的像素从 58% 降到 31%。`R-compare-orig-off-on.png` 依次是原图、关、开。
- 真实重跑 R/C/D/G 时中转返回 429「No image generation quota is currently available」（19:43–19:44），没有新的真实图。

### 改字幕 / 去字：用 comic-text-detector 决定擦哪些像素
- 气泡位置和 OCR 仍然用规则检测；去字蒙版改用 comic-text-detector（ONNX，GPL-3.0）整页检测、按页缓存，再裁到当前字幕框。模型不随项目分发：首次使用会询问是否下载约 91MB，下载后用 SHA-256 校验，不符就删除、不加载。
- 「保留拟声词」（默认开）：只擦字幕框里的字，画面上的效果字不动。
- 回退：没装模型、拒绝下载或模型不可用时，用原来的规则蒙版并提示；模型可用但框里没找到字（规则把人脸、猫等误认成气泡）时，什么都不擦，提示用画笔手动涂。
- 同一时间只处理一页：第二页的请求排队最多 90 秒，而不是直接报忙。实测报忙会退回规则蒙版，把猫擦掉。
- 测试：`scripts/manga-text-detector-test.py`（下载必须先同意、校验失败删除文件、排队、状态字段；第 4 页的人脸和猫蒙版覆盖率为 0，真气泡里的字被覆盖），E2E 第 33 个流程（第 4 页框住猫：不擦；框住气泡：只擦字）。CI 没装模型时，模型相关测试自动跳过。
- 补充（CI 修复）：整块偏色扣除只在外圈也偏了同方向时才执行，用来区分模型偏色和用户想要的改色。如果只有选区里整体变色、外圈没变（例如「把衣服改红」），保留用户要的颜色，不扣回去。浏览器验收测试里的模拟编辑是整张图统一加色，所以在套索和画笔两项检查里关闭了色调匹配和「只替换改动部分」，这两个功能各自有单独的测试。
