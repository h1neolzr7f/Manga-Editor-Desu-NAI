# 新手快速上手（5 分钟）

打开编辑器后，你看到的就是「想做什么？」首页。每件事都是一个小向导：一步一步点，参数都已经帮你选好；想要更多控制时勾「高级」。

## 0. 第一次使用
1. **导入漫画页**：点首页大按钮「导入漫画页（可多选）」，或把图片拖进来。
2. （可选）**服务设置**：右上角 `⋯` → 「服务设置」。在这里一次填好 AI 改图（GPT）地址/Key、NovelAI Token，每项都有「测试连接」（不花钱）。本机文字识别、去字、抠图不需要任何 Key。

## 1. 常用任务

| 我想… | 点哪个 | 会发生什么 |
|---|---|---|
| 把对白换成中文 | **改字幕** | 打开就自动识别本页文字 → 在每条下面改台词 → 「应用」。旧字自动擦掉，新字是可编辑的文字图层。识别不到的点「手动框选字幕」。 |
| 换掉一个角色 | **换角色** | 自动找出人物（橙色虚线）→ 点一下要换的人（或拖框调整范围）→ 上传新角色参考图 → 「生成」→ 「对比原图」→ 「应用」。其他格同一角色可一键换（不确定的默认不勾）。默认保留原表情和姿势。 |
| 去掉杂物 / 修瑕疵 | **修瑕疵 / 去杂物** | 框住不想要的东西 → 生成 → 应用。 |
| 抠出人物当新图层 | **分层** | 「开始框选」或「智能点选」点一下人物 → 3 个候选挑一个 → 变成新图层。 |
| 随便改 | **自定义修改** | 框一个区域，写一句话（例如「把天空改成黄昏」）→ 生成 → 应用。 |
| 从零画一页 | **画一页漫画** | 选 3 格或 4 格 → 每格写一句画面 + 台词 → 「生成整页」（会先提示花费）。 |
| AI 生图 | **AI 生图** | 用 NovelAI；没填 Token 时会直接带你去填。 |

## 2. 随时可用
- **撤销 / 重做**：任务栏左侧，或 `Ctrl+Z` / `Ctrl+Y`。所有 AI 结果都是新图层，可单独删除。
- **保存**：任务栏「保存」（`Ctrl+S`），下次「打开项目」继续。
- **导出全部**：任务栏「导出全部」→ 一个 zip，里面每页一张 PNG + 项目文件。
- **快捷键**：按 `F1`。
- **浅色 / 深色**、**专业模式**（全部原始工具）：`⋯` 菜单。

## 3. 出问题时
- 提示「图像服务 N 秒没有响应」：中转站卡住了，画布没有改动，稍后点「重试」。
- 提示要下载本机模型：只在第一次用到时下载（会先问你），之后离线可用；不用时 10 分钟后自动释放内存。
- 找不到人物 / 文字：可以手动拖框，自动结果只是建议。
