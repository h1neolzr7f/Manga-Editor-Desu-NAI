## 可运行功能

- GPT 文生图、透明 PNG、原图编辑及参考图辅助生成。官方 `/v1/images/generations` 使用 JSON，`/v1/images/edits` 使用 multipart，目标图始终第一张，其后是按用途标记的参考图。
- 自定义 HTTPS API 地址、模型、质量与会话 API Key。支持标准 Images 协议中转，未实测供应商明确保持 `custom-unverified` 状态。
- 右键短按原菜单；拖动超过 6 屏幕像素创建矩形 AI 选区；套索、原图像素坐标调整、画笔、橡皮、全选、清空遮罩。
- 人物身份、服装、姿势、画风四种参考图用途；人物替换必须提供身份参考。角色档案保存外观约束与参考图，随所在页工程保存。
- 人物替换、服装配饰、表情、背景、删除物体、自由修改共用一个请求/预览/应用流程。
- 原尺寸局部内容以白色填充扩展到供应商输出规格，原始像素不缩放；结果比例或分辨率不足即拒绝回贴。只可向下采样更大且同一比例的输出。
- 修改前后比较，确认后添加独立补丁图层，保留原图、页面尺寸和图层顺序。允许编辑区域之外补丁 Alpha 恒为零，抗锯齿裁剪边缘也保持原始像素。
- 取消预览、切页、删除目标或修改画布后拒绝过期结果；在 Fabric 解码期间取消也不会插入图层。
- 字幕优先选择已有 Textbox / VerticalTextbox 及其气泡关联；准确原文逐字保存，支持横排/竖排、明确选择纯白覆盖层。复杂背景清除交给单独的 GPT 预览流程。
- 字幕支持 `把“原句”改成“新句”` 指令和多页精确替换清单；清单先预览，逐页验证 GUID 与原文，再应用可撤销的文字事务。

## 操作步骤

1. 安装 Node 和 Python，执行 `npm ci`；用原启动器或 `python 99_server.py` 打开 `http://127.0.0.1:8000/index.html`。GPT 请求需要本地 Python 服务，直接 file:// 打开页面仍需服务运行。
2. 导入图片或打开漫画工程。右键短按检查原菜单；右键拖拽选区后松开，打开 GPT 编辑窗。
3. 展开接口设置，填写官方地址或第三方中转地址、供应商支持的准确模型名及 API Key。Key 仅在当前会话内存中保存，不写工程、localStorage、日志或仓库。
4. 导入参考图并选择用途；人物替换选“人物身份”。输入准确要求；需要更细遮罩时使用“画笔精修遮罩”。
5. 点击“生成预览（收费）”，核对前后对比，再“确认应用”。任务不自动重试。停止本地等待不能保证供应商停止计费。
6. 在图层面板检查新增补丁，切换其可见性对比原图；撤销、重做、保存 LZ4 并重开，检查页面尺寸、裁剪关系与补丁保留。
7. 选择字幕或气泡，点击“字幕”，输入准确台词和方向。没有可用本机 OCR 时直接手动输入，不伪造识别结果。
8. 多页清单格式：`[{"pageGuid":"实际页面GUID","layerGuid":"实际文字GUID","text":"准确台词","expectedBefore":"原台词"}]`。先预览、再应用；错误页或不一致原句应拒绝。

## 自动验证与证据

执行 `npm test`：26 个离线回归文件，包括 18 个 Python Images 协议测试、14 个历史/分镜回归、11 个图片保存/重试场景、8 个审核状态回归，以及原有导出、分镜导入、模拟器、资产、页面和画笔检查。这些测试使用确定性夹具，不代表真实供应商生图已经通过。

真实浏览器测试（需要 Playwright Chromium；可用 `npx playwright install chromium` 安装）:

```sh
# 另一个终端运行 python 99_server.py
npm run test:gpt-browser
npm run test:subtitles-browser
```

浏览器使用实际完整页面、Fabric、Canvas 与 LZ4 工程格式，候选图片为确定性像素夹具。普通选区外像素变化 0；旋转/翻转/裁剪图层的遮罩外像素变化 0；工程背景与发送的原图像素差异 0。验证原图保留、撤销/重做、保存重开、取消时解码、过期结果、右键菜单/拖拽、套索、遮罩及精确字幕。

真实收费 API 验证脚本明确要求 `--allow-paid-api`，不会自动重试；凭证文件应在仓库外。`--image` 可重复指定目标与参考 PNG，`--mask` 为同尺寸透明区域编辑遮罩。2026-10-09 使用用户授权的第三方凭证尝试单次生成，在 DNS 解析阶段返回 `endpoint_dns`，未连接到供应商，未发送 Key，没有生成收费请求。该供应商的真实生图、改图、参考图效果仍未验收。不要把离线测试通过标记为真实 API 通过。

Windows CI 在分支/PR 构建，运行离线测试和浏览器回归，再打包嵌入式 Python/Node、校验源码与安装字节 SHA256，附完整 GPL 源码 ZIP、安装 EXE、便携 ZIP 和 build-manifest。只有明确标签或显式 release_tag 才进入发布任务；本次不触发发布。以实际 Actions 结果为准，不以工作流代码存在代替构建通过。

## 当前边界

- 自然语言辅助定位尚未实现；本阶段靠手动矩形、套索、遮罩。
- 最大编辑选区受 1024×1024 / 1536×1024 / 1024×1536 输出规格限制。大于输出规格会明确拒绝，尚无分块高分辨率编辑。
- 角色身份属于参考图与提示约束，不能保证模型跨分镜完全一致；需要人工逐次验收。档案当前随所在页保存，尚未建立整本漫画共享档案库。
- 浏览器 TextDetector 并非普遍可用；目前无额外 OCR 模型下载，也不自动擦除复杂背景或改写文字。
- 本地撤销按页管理；批量字幕逐页预检和保存，不提供跨多页的单步原子撤销。若应用阶段存储失败，已经保存的页面仍然保留其可撤销修改。
- Python 代理直接连接经公共 DNS 验证的 HTTPS 地址，不使用系统代理，也不跟随重定向；无法解析/连接的网络环境需要使用可访问的标准中转地址。
- 输入 PNG 每张 8 MiB、合计 24 MiB，最多目标图加四张 UI 参考图；Alpha 遮罩小于 4 MiB。外部结果下载不转发 API Key，私人地址及重定向拒绝。
- 供应商成功仅表示请求返回了图片，不代表画质、身份或文本准确通过审核。任何模型请求失败都不应用图层。
