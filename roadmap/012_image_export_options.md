# 012: 画像エクスポート機能の拡充

## 規模: M (中)

## 概要
現在の画像エクスポート（PNG/SVG）に加え、より多くの出力オプションを提供する。

## 現状の問題
- ~~出力サイズの指定ができない（キャンバスサイズ固定）~~ → ダウンロード DPI と倍率上限で対応済み
- ~~JPEG形式での出力がない（写真系素材が多い場合にファイルサイズが大きい）~~ → JPEG / WebP と品質指定に対応済み
- ~~WebP形式に未対応~~ → 対応済み
- 一括エクスポート（全ページ）の操作が煩雑

## 対応済み (PNG/JPEG/WebP + 品質 + 上限)
`js/core/util/image-util.js` の `exportCanvasDataURL` / `resolveExportMultiplier` を追加。
長辺 8192px・総画素 40MP を超える場合は倍率を自動縮小し、超過時はトーストで通知する。
UI は 画布 → 导出格式 / 导出品质 / 下载 DPI（max 1800）。

## 修正内容
- エクスポートダイアログの新規作成
  - 形式選択: PNG / JPEG / WebP / SVG
  - 品質設定: JPEG/WebPの圧縮率指定
  - サイズ指定: 等倍 / 指定サイズ / 解像度DPI指定
  - 命名規則: ファイル名テンプレート
- 全ページ一括エクスポート機能
  - ZIP形式でまとめてダウンロード
  - 連番ファイル名
- エクスポートプリセットの保存

## 影響範囲
- 画像ダウンロード機能全般
- ボトムバーの複数ページ管理
