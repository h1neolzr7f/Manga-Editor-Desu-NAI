# Manga Editor Desu · nai学长魔改版

**Unofficial modified build 1.0.0** (2026-08-14)

[中文](README.md) · [日本語](README_JP.md)

This keeps the original English name **Manga Editor Desu**, and adds **nai学长魔改版** to mark the fork.

It is a **modified build** of [Manga Editor Desu!](https://github.com/new-sankaku/manga-editor-desu) by new-sankaku — **not** an official upstream release, and **not affiliated** with the original author. The panel editor, bubbles, layers, knife tool, and project save/load still come from Desu. This pack switches generation to **NovelAI** and adds a Windows one-click launcher plus a chat/web simulator.

## Run (Windows)

Double-click `一键启动.bat`. Open `http://127.0.0.1:8000/index.html`. Do not use `file://`. Paste your own NovelAI token. Generation spends credits.
