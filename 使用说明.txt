======== 安装与启动 ========

【普通用户推荐：EXE 安装器】
1. 从 GitHub Releases 下载「Manga-Editor-Desu-NAI-Setup-*.exe」。
2. 双击安装，可选择创建桌面快捷方式。
3. 从开始菜单或桌面打开「Manga Editor Desu NAI」。
4. 安装器已内置 Python、Node.js 和 Pillow，不需要另装环境，也不需要管理员权限。

【便携包 / 源码】
1. 解压整个文件夹，不要只拷贝单个 html。
2. 确保命令行能运行 Python 3；批量素材工具还需要 Node.js。
3. 双击「一键启动.bat」。

浏览器应打开 http://127.0.0.1:8000/index.html
不要用 file:// 直接打开 index.html，出图、抠图、素材都会不正常。
改完页面后若显示旧界面，按 Ctrl+F5 强制刷新。

需要：Windows 10/11、Chrome 或 Edge。
出图还需要你自己的 NovelAI 访问令牌（会消耗 NovelAI 积分）。

======== 第一次用 ========

1. 打开「设置 / NovelAI 设置」，粘贴访问令牌（只出图才需要）。
2. 要假聊天、影片站、弹幕：点左侧「模拟器」，选一种单开，改字后可点「放入漫画」。
3. 要格子分镜，两条路都可以：
   - 点左侧「模板」，选一个分镜铺到这一页；
   - 或点「更多 → 页面」→「自定义页面」（会铺满整页格子），再点「切割格子」自己切开。
4. 空画布中间如果弹出「打开模拟器 / 去选分镜」，可点右上角 × 或「自己裁剪」关掉；之后在「帮助 → 新手教程」里还能再看。
5. 在格子里写提示词，点「生成」（会花积分，界面会确认）。
6. 画布缩放：Ctrl+滚轮，或顶栏 − / % / + / 适应。
7. 整页贴到某个格子：选中刚放上去的模拟器后点「贴到格子」。

导演分镜文案（可选）：在设置里填 OpenAI 兼容网关。最终格子出图仍只走 NovelAI。

======== 常用功能 ========

分镜 / 刀切 / 气泡 / 图层 / 网点 / 笔刷 / 多页 / 保存
  这些来自原版 Manga Editor Desu，用法大体相同。
  工程保存为「DESU-nai学长魔改.lz4」。
  自定义页面和竖页/横页 A4 一样会铺满一整格，再用刀切开。

模拟器
  对话、网页、零件。都是通用界面样式，没有真实站名或商标。
  聊天皮肤不能直接当 NAI 出图；要出漫画请放到分镜格子里再生成。

抠图
  左侧「抠图」。启动器会打开本机 8765 抠图服务。
  EXE 已包含颜色抠图所需的 Pillow。rembg 和体积较大的模型不随安装器打包；
  需要动漫/人像模型时，再按 local_tools/README.md 选装。

自定义笔刷
  左侧笔刷 → 自定义笔刷。可调大小、间距、硬度，导入笔尖图，保存或导出 JSON。

======== 不要做 ========

- 不要把 .env、令牌、user_data/ 里的私人图发到网上或推进 Git。
- 不要把本包当成 ComfyUI / WebUI / Forge 前端（这些已关掉）。
- 点「生成」会花 NovelAI 积分，批量生成前看清确认框。

======== 打不开时 ========

- EXE 安装版：先看 user_data\start.log；文件损坏时重新运行安装器修复。
- 便携包 / 源码：确认命令行能运行 python。
- 8000 端口被占用时，关掉旧窗口或相关 python，再开一次。
- 更完整的仓库说明见 README.md。
