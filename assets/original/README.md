# Original assets

Public, project-original decorations live in `starter/` and `site-ui/`.

- `starter/` geometric manga marks (speed lines, emotion glyphs, silhouettes, frames)
- `site-ui/` generic website chrome (dark video tube, danmaku player, image board)

No third-party character or trademark art. Layout-only palettes; no real site names or logos.

The editor seeds them into the asset library on load. Click 恢复入门包 if the list is empty.
