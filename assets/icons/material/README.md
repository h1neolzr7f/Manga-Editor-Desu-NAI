# Default icon-library SVGs (bundled)

The 21 icons listed in `initialIcons` (js/core/svg/google-icon-names.js), Material Icons
"filled" style, copied verbatim from fonts.gstatic.com so the shape panel's default icon
set works offline and the editor makes no external requests at startup.
