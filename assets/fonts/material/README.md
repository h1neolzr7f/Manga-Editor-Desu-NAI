# Material Icons / Material Symbols Outlined (bundled)

Copied verbatim from Google Fonts (fonts.gstatic.com) so the editor's icons render
offline and in regions where Google Fonts is blocked. Without them every icon
shows its ligature name as text (for example "visibility", "forum").

- material-icons.woff2 — Material Icons v142
- material-symbols-outlined.woff2 — Material Symbols Outlined v199
