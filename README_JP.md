コマ割り・吹き出し・レイヤー・ナイフ・トーン・ブラシ・複数ページ保存は原作に基づきます。画像生成は **NovelAI** 専用、Windows のワンクリック起動と汎用シミュレータを追加しています。

## 起動（Windows）

`一键启动.bat` を実行し、`http://127.0.0.1:8000/index.html` を開きます。`file://` では使わないでください。生成には NovelAI のトークンが必要で、クレジットを消費します。
